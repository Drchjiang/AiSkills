# AI Skills 集合

本仓库汇集了用于 AI 助手（如 Claude、DeepSeek 等）的技能总结（Skills），将专业的网页制作、幻灯片生成、设计系统等知识“打包”成结构化文档，直接喂给 AI 即可让它快速掌握特定领域的实践规范。

## 🧰 技能列表

### 1. HTML 幻灯片/报告生成器
- **文件**：[html-ppt-skill.md](./html-ppt-skill.md)
- **能力**：生成现代化、可编辑、带字体特效、支持多页动画的 HTML 幻灯片，内置演讲者模式、PPTX 导出接口等。
- **适用场景**：制作产品演示、数据分析报告、技术分享等网页版 PPT。

### 2. taste skill
Taste Skill 是一个为 AI 编程助手设计的“反模板化”前端框架技能包。它的核心目标是让 AI 生成的界面不再千篇一律，而是具备更强的布局、排版、动效和间距设计感
